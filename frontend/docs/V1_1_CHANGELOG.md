# EMP-PORTAL-V1.1 Change Record

Added industrial requirement-planning fields:
1. Requirement Priority
2. Required Within
3. Preferred Start / Joining Date
4. Expected Engagement Duration
5. Target Completion Date
6. Optional Budget / Commercial Range

Rationale: industrial requirements differ in urgency, planned start date, engagement duration and project delivery expectations. Priority is intentionally separate from the required-within window.
